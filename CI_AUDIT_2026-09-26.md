# CI / Commit Audit — 2026-09-26

This audit covers the repository history and GitHub Actions state observed on 2026-09-26.

## Repository history

- 163 commits were present on `main` at audit time.
- 300 GitHub Actions runs were observed across the available run history inspected.
- 16 commits had no GitHub Actions run associated with their exact commit SHA. These are not automatically failures; most are changes that did not match a workflow path or were historical/test commits.
- 58 commits had at least one failed Actions run associated with their exact SHA. This is a historical event count, not a count of currently broken commits; repeated pushes, superseded Pages deployments, and later fixes can produce failures on an older SHA.

## Track 3 sync history

Before the final repairs, the sync pipeline exposed several real defects:

1. Observation CSV schema drift caused `csv.DictWriter` to reject newly added task fields.
2. Module 1 validation had brittle numerical and source-invariant checks.
3. The Track 3 workflow did not trigger when the Module 1 validator changed.
4. `observation_queue.json` did not expose the count fields that the workflow validator expected.
5. The generated site-domain set omitted schema-defined `regulatory` and `independent_corroboration` domains.
6. The canonical evidence-count validator initially omitted power and cooling observation records.
7. Concurrent sync runs could race while pushing generated snapshots.
8. The workflow refreshed `data/module1_radar_summary.json` but did not include that file in its generated-artifact commit.

All eight issues were repaired in the current pipeline.

- Run 111 — success
