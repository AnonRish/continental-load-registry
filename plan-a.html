AI 2040 Plan A · Track 3 Research Bridge

A public index for using this repository as an independent, reproducible contribution to the AI 2040 Plan A discussion around Track 3: verifying the absence of secret compute.

Scope and attribution

This repository is not an AI Futures Project publication, does not speak for AI 2040, and does not certify a treaty or verification regime. It maps public AI 2040 concepts onto concrete open-source evidence, data-engineering, and research tasks so other researchers can reproduce, challenge, or extend the work.

Primary AI 2040 references

Track 3 · Verification Plan Plan A · Covert AI Projects Plan A scenario

AI 2040's public Track 3 page identifies the goal as verifying the absence of secret compute. The Covert AI Projects supplement describes accounting for pre-deal compute, tracing sales/resales to physical end use, and locating remaining unaccounted compute.

What to contribute next

The most consequential extensions are not another dashboard layer. They are evidence chains that connect production → sale → transfer/resale → current owner → physical location → inspection, plus a separately auditable pathway for unrecorded compute → external discovery → candidate site → physical evidence → accounting resolution.

Use the Track 3 evidence issue template or submit a focused pull request with the source, dates, raw value, normalized value, scope, and provenance.
