A database broader than Epoch.

This page joins source-backed facility universes instead of treating any one index as the world census. Epoch remains the frontier-AI anchor; Compute Atlas expands the U.S. compute footprint; Data Center Index expands the global campus footprint. Overlaps are linked, not double-counted in the conservative unique view, and every record keeps its source universe and provenance.

How this gets wider over time

The page prefers local snapshots generated by the registry's sync workflow, with live-source fallback when a snapshot is not yet available. The architecture is designed to add additional source universes without merging them blindly: source discovery → normalization → conservative entity resolution → provenance → searchable surface → historical snapshot.
