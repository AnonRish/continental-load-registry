# Track 3 physical-coordinate coverage audit — 2026-09-27

This audit makes the physical-observation gate explicit for the 93 Epoch reference sites.

**Rules**

- A site is **RESOLVED** only when a latitude/longitude is retained in the canonical coordinate artifact.
- Coordinate precision is preserved. A campus-level or third-party coordinate is not upgraded to a building-footprint claim.
- A resolved coordinate enables scene acquisition; it does not prove facility identity, energization, AI compute, ownership, or covert status.
- An unresolved site remains outside physical interpretation. Missing imagery or a failed geocoder is never interpreted as absence.

The machine-readable audit is generated by `build_track3_geo_audit.py` and published with the physical verification pipeline.
