Public static API

The repository publishes machine-readable JSON as stable GET resources. These are static, versioned GitHub Pages resources—not a server-side query API.

Current Track 3 facilities

/api/v1/facilities.json — 93 facility records with coordinates, ownership/user fields, grid status, queue ID when known, evidence counts and source URLs. CSV and JSON.

Queue/facility record API

/data/facility_records/index.json — 1,558 published registry records indexed into RTO shards.

Each RTO index exposes its shard URLs; shards are directly downloadable JSON.
