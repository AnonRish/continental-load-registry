Application Status

This list provides the status of all connection proposals (transmission, load, generation and ancillary services) that have submitted a connection application package and executed the required agreement.

Due to their confidential nature, technical feasibility reports are not posted.

"Active" in Status column indicates that assessment work, possibly an addendum, is in progress and the SIA report or addendum has not been finalized yet . A report link may appear for an active status, if the IESO is currently working on an addendum.

Final System Impact Assessment reports and addendums referenced on this page but no longer posted can be obtained by contacting Connection.Assessments@ieso.ca. Please provide the CAA ID, the project name and advise whether it needs to be provided in an accessible format. Please allow a minimum of one business day for a response.
